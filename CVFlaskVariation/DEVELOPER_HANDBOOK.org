* Project Overview

** Description
A Flask-based real-time object detection and navigation system for blind/visually impaired users using YOLO11, featuring camera access, object tracking, collision detection, pathfinding, and audio announcements.

** Tech Stack
- Backend: Python 3.x, Flask, PyTorch, Ultralytics YOLO, OpenCV
- Frontend: JavaScript ES6 Modules, HTML5 Canvas, Web Speech API
- ML Model: YOLO11 (yolov8x-oiv7.pt)
- Tracking: DeepSORT with MobileNet embeddings
- Additional: Flask-CORS, NumPy, SciPy, Pillow

** Key Features
- Real-time object detection with YOLO11
- Object tracking with DeepSORT
- Collision detection and prediction
- Reactive navigation for dynamic obstacle avoidance (UPDATED 2025-10-15)
- Perspective-aware movement directions (UPDATED 2025-10-15)
- Gyroscope-based rotation correction
- Audio announcements with priority queue
- Voice command support
- SSL/HTTPS support

** Routes (API Endpoints)

*** app/routes/detection.py
*Location:* [./app/routes/detection.py:34]

*Purpose:* Handle real-time object detection requests from browser

*Endpoints:*
- ~POST /detect_image~ - Process image and return detections with tracking
- ~GET /test_audio~ - Return sample detection data for audio testing

*detect_image() Flow:*
1. Receive base64 image from browser
2. Apply gyroscope-based rotation correction
3. Run YOLO inference (optimized for real-time)
4. Filter blacklisted classes
5. Apply confidence filtering (>30%)
6. Deduplicate overlapping same-class detections
7. Update DeepSORT tracking
8. Calculate movement and collision predictions
9. Return JSON with detections, tracking, collision warnings

*Response Fields:*
- detections: Array of tracked objects with bbox, confidence, movement, collision
- success: Boolean status
- image_size: [width, height]
- filtered_count: Number of blacklisted detections removed
- rotation_applied: Degrees rotated based on gyroscope
- tracking_enabled: Boolean
- tracked_count: Number of confirmed tracks
- collision_warnings: Number of objects with collision risk
- processing_time_ms: Total processing time

*** app/services/collision_detector.py
*Location:* [./app/services/collision_detector.py:16]

*Purpose:* Movement analysis and collision prediction for blind safety (UPDATED 2025-10-15)

*Movement Directions (Perspective-Aware):*
- stationary - Displacement < 5 pixels
- moving_right - Angle -45 to 45 degrees
- moving_closer - Angle 45 to 135 degrees (approaching user, was "moving_down")
- moving_left - Angle 135 to 180 or -180 to -135 degrees
- moving_away - Angle -135 to -45 degrees (receding from user, was "moving_up")

*IMPORTANT:* Directions use camera perspective mapping:
- "moving_closer" = object moving toward bottom of frame = approaching user
- "moving_away" = object moving toward top of frame = receding from user
- Eliminates confusing "up/down" terminology for blind users

*Speed Classes:*
- slow - < 2.0 pixels/frame
- medium - 2.0 to 10.0 pixels/frame
- fast - > 10.0 pixels/frame

*Collision Severity:*
- high - Will enter user zone (15% of frame radius)
- medium - Approaching user zone (within 2x radius)
- low - Approaching from distance (within 3x radius)
- none - Not approaching or stationary

*Purpose:* UI rendering, statistics, FPS counter, and canvas drawing

*Drawing Features:*
- Bounding boxes color-coded by distance or track ID
- Labels with class name, confidence, track ID
- Direction and distance information
- Movement indicators (arrows and speed)
- Trajectory lines for tracked objects
- Collision warnings with pulsing circles
- Predicted positions for approaching objects
- Navigation path visualization
- User position marker
- Goal marker

*Detection Queue:*
- MAX_DETECTION_ITEMS: 1 (only latest)
- Circular queue with FIFO
- Grouped by class name
- Updates existing entries

*Color Coding (Distance):*
- Red (#ff0000) - Immediate (very close)
- Orange (#ff8800) - Near (close)
- Yellow (#ffff00) - Medium (medium distance)
- Green (#00ff00) - Far (far)
- Blue (#0088ff) - Distant (very far)
