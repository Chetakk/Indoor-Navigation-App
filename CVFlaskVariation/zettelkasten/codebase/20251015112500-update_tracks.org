* Description

Updates DeepSORT tracker with new detections from current frame.
Maintains persistent object IDs across frames and filters to confirmed tracks.

* Parameters

- session_id :: str - Unique session identifier
- detections :: list[tuple] - List of (bbox_ltwh, confidence, class_name)
- frame :: np.ndarray - Current frame image in BGR format

* Returns

list[Track] - Confirmed track objects with attributes:
- track_id :: int - Unique persistent ID
- det_class :: str - Object class name
- det_conf :: float - Detection confidence
- ltrb :: list[float] - Bounding box [left, top, right, bottom]

* Algorithm

1. Get or create tracker for session:
   #+begin_src python
   tracker = self.get_tracker(session_id)
   #+end_src

2. Update tracker with detections:
   #+begin_src python
   tracks = tracker.update_tracks(detections, frame=frame)
   #+end_src

3. Filter to confirmed tracks only:
   #+begin_src python
   confirmed_tracks = [t for t in tracks if t.is_confirmed()]
   #+end_src

4. Update trajectory histories:
   #+begin_src python
   for track in confirmed_tracks:
       center_x = (ltrb[0] + ltrb[2]) / 2
       center_y = (ltrb[1] + ltrb[3]) / 2
       track_key = f"{session_id}_{track_id}"
       self.track_histories[track_key].append((center_x, center_y))
   #+end_src

5. Return confirmed tracks

* Track States

See [[id:20251015114600-deepsort_track_states][DeepSORT Track States]]:
- Tentative :: New detection, not yet confirmed
- Confirmed :: MIN_TRACK_INIT consecutive matches (2 frames)
- Deleted :: No match for MAX_TRACKER_AGE frames (10 frames)
