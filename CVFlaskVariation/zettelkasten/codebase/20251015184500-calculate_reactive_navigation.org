* Description

Core reactive navigation algorithm that analyzes current scene and provides
immediate safe walking direction toward goal. Runs continuously (every 500ms)
to adapt to dynamic obstacles.

Replaces [[id:20251015112700-astar_pathfinding][astar_pathfinding()]] for real-time blind navigation.

* Parameters

- detections :: list[dict] - Current detected objects with bboxes, velocity
- goal :: [x, y] - Goal position in pixel coordinates
- start :: [x, y] - Current user position in pixel coordinates
- image_width :: int - Image width in pixels
- image_height :: int - Image height in pixels

* Returns

dict with (all values JSON-safe native Python types):
- reached_goal :: bool - True if within 1px of goal
- safe_direction :: [x, y] - Normalized direction vector to walk
- goal_direction :: [x, y] - Direct direction to goal (for comparison)
- distance_to_goal :: float - Distance to goal in pixels
- obstacles :: list[dict] - Top 5 threatening obstacles
- guidance :: dict - Voice guidance messages
- deviation_angle :: float - Deviation from direct path (degrees)

*IMPORTANT:* All values explicitly converted to native Python types (bool, float, list)
to ensure JSON serialization compatibility with Flask's jsonify().

* Performance

- Typical obstacles: 5-20 per scene
- Computation: < 10ms
- Obstacle analysis: O(n) where n = detections
- Direction finding: O(obstacles * 16) for 16 direction samples
- Total: O(n) linear in number of detections

Very fast compared to A* pathfinding (100-500ms).

* Advantages Over A*

1. Handles moving obstacles naturally
2. No path invalidation problem
3. Lower computational cost (< 10ms vs 100-500ms)
4. Works with partial knowledge
5. Always provides guidance (never "no path found")
6. Real-time adaptation to scene changes
