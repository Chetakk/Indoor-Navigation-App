* Audio System Design

** Priority Levels
1. Critical - Immediate collision danger
2. High - Approaching objects, new hazards
3. Normal - General detections
4. Low - Background information

See [[id:20251015121800-audio_priority_system][Audio Priority System]]

** Queue Management
- FIFO with size limit (1 item)
- Latest information prioritized
- Old announcements discarded

See [[id:20251015120900-audio_priority_queue][Priority Queue]]

** Interruption Logic
- Critical: Cancel all, speak immediately
- High: Cancel current, speak immediately
- Normal/Low: Queue if speaking

** Speech Parameters
- Critical: 1.2x rate, max volume
- High: 1.1x rate, max volume
- Normal: 0.95x rate, 90% volume

* Detection Announcements

** What Is Announced
- Object class name
- Distance estimation (close, medium, far)
- Direction (left, right, center, ahead)
- Movement ([[id:20251015184800-perspective_aware_movement][perspective-aware]]: "approaching", "moving away", not "up/down")
- Collision warnings (if approaching)
- [[id:20251015184700-generate_voice_guidance][Navigation guidance]] ("Turn left, 3 meters", "Walk straight ahead")

** Announcement Frequency
Dynamic based on distance:
- Immediate (very close): Every 2 seconds
- Near: Every 4 seconds
- Medium: Every 6 seconds
- Far: Every 8 seconds

See [[id:20251015121900-announcement_intervals][Announcement Intervals]]

** What Is NOT Announced
- Objects leaving view (silent cleanup)
- Low confidence detections (< 30%)
- Blacklisted classes (buildings)

* Tracking Announcements

- New objects detected
- Objects started moving
- Direction changes
- Speed changes
- Long stationary objects (every 15s)

See [[id:20251015117900-announce_detections][announceDetections()]]

* Voice Commands

** Basic Commands
- "start" / "begin" - Start detection
- "stop" / "pause" - Stop detection
- "where" / "what" - Announce current objects
- "help" - List commands

** Navigation Commands
- "find door" - Navigate to door
- "find chair" - Navigate to chair
- Works with any of 600+ object classes

See [[id:20251015121200-voice_commands_list][Voice Commands List]]

* Performance for Blind Users

** Target Metrics
- Detection latency: <1000ms (1 FPS minimum)
- Audio latency: <300ms
- Voice command response: <500ms

** Real-Time Requirements
- Immediate collision warnings (critical priority)
- Fast announcement of new objects
- Responsive voice commands
