* Per-Session Tracking

Each user session gets isolated tracker:
#+begin_src python
if session_id not in self.trackers:
    self.trackers[session_id] = DeepSort(...)
#+end_src

Why?
- Prevents cross-user ID conflicts
- Allows independent tracking state
- Session cleanup on disconnect

* Memory Management

** Per Session
- DeepSort tracker: ~50-100MB
- Track histories: ~1KB per track

** Cleanup
- Manual: [[id:20251015115300-reset_session][reset_session()]]
- Automatic: None (relies on session expiry)

Consider implementing auto-cleanup for abandoned sessions.

* Thread Safety

Not thread-safe. Flask handles requests sequentially per session
due to session management, so this is acceptable.

* Session Lifecycle

1. First detection → Create tracker
2. Subsequent detections → Update tracker
3. User stops → reset_session() called
4. Session expires → Tracker remains (memory leak)

See [[id:20251015120600-session_lifecycle][Session Lifecycle]]
