* Description

Implements A* algorithm to find shortest safe path through occupancy grid.
DEPRECATED: Use [[id:20251015184500-calculate_reactive_navigation][calculate_reactive_navigation()]] for dynamic environments.

* Parameters

- grid :: np.ndarray - 2D occupancy grid (0=free, 1=obstacle)
- start :: (x, y) - Start position in grid coordinates
- goal :: (x, y) - Goal position in grid coordinates

* Returns

- list[(x, y)] - Waypoints from start to goal
- None - If no path exists

* Algorithm

See [[id:20251015119300-astar_algorithm][A* Algorithm]] for general explanation.

** 3. Main Loop
#+begin_src python
while open_set:
    current = heappop(open_set)

    if current == goal:
        return reconstruct_path(came_from, current)

    for neighbor in get_8_neighbors(current):
        if grid[neighbor] == 1:  # Obstacle
            continue

        move_cost = 1.414 if diagonal else 1.0
        tentative_g = g_score[current] + move_cost

        if tentative_g < g_score.get(neighbor, infinity):
            came_from[neighbor] = current
            g_score[neighbor] = tentative_g
            f_score[neighbor] = tentative_g + heuristic(neighbor, goal)
            heappush(open_set, (f_score[neighbor], counter, neighbor))
            counter += 1
#+end_src

* Movement Costs

- Cardinal (↑↓←→): 1.0
- Diagonal (↗↘↙↖): 1.414 (√2)

Diagonal movement allowed for smoother paths.

* Complexity

- Time: O(b^d) where b=branching factor (8), d=depth
- Space: O(b^d)
- Typical: 100-500ms for 640x480 image with 20px grid

* Optimality

A* is:
- Optimal :: Finds shortest path (given admissible heuristic)
- Complete :: Always finds path if exists
- Admissible :: [[id:20251015119400-manhattan_distance][Manhattan distance]] never overestimates
