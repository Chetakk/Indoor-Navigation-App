* Overview

YOLO-based object detection service. Manages model loading, inference,
and class filtering. Singleton pattern for resource efficiency.

* Model Architecture

See [[id:20251015118700-yolo11_architecture][YOLO11 Architecture]]

** Model Variants
- yolov8n-oiv7.pt :: Nano - Fast, less accurate
- yolov8s-oiv7.pt :: Small
- yolov8m-oiv7.pt :: Medium
- yolov8l-oiv7.pt :: Large
- yolov8x-oiv7.pt :: Extra Large - Slow, most accurate (current)

** Blacklist

* Performance

See [[id:20251015114200-yolo_performance][YOLO Performance Analysis]]

** GPU Mode (RTX 3060)
- Inference: 60-100ms
- Total throughput: ~10-16 FPS

** CPU Mode (i7)
- Inference: 100-250ms
- Total throughput: ~2.94 FPS

* Device Management
