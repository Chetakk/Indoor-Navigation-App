* Description

Runs YOLO11 inference on an image to detect objects. Handles confidence
thresholds, NMS, and device management.

* Parameters

- image :: np.ndarray - Image in BGR format (OpenCV)
- conf :: float (optional) - Confidence threshold 0.0-1.0
- iou :: float (optional) - IOU threshold for NMS
- max_det :: int (optional) - Maximum detections per image
- verbose :: bool (default=False) - Print detection info

* Returns

YOLO results object with:
- boxes :: Boxes - Detection bounding boxes
  - xyxy :: tensor - Box coordinates [x1, y1, x2, y2]
  - conf :: tensor - Confidence scores
  - cls :: tensor - Class IDs

* Default Values

From [[id:20251015114100-constants_detection][Detection Constants]]:
- DEFAULT_CONFIDENCE_THRESHOLD = 0.30
- DEFAULT_IOU_THRESHOLD = 0.65
- MAX_DETECTIONS = 50

* Algorithm

1. Validate model is loaded
2. Apply default thresholds if not provided
3. Call YOLO model with configured parameters:
   #+begin_src python
   results = self.model(
       image,
       verbose=verbose,
       device=self.device,
       conf=conf,
       iou=iou,
       max_det=max_det
   )
   #+end_src
4. Return results object

* Technical Details

** Confidence Threshold
Filters out detections with confidence < threshold.
Higher = fewer false positives, more false negatives.

** IOU Threshold
Used in NMS to remove overlapping boxes.
See [[id:20251015114400-nms_algorithm][NMS Algorithm]] for details.

** Device Management
- Automatic GPU detection via torch.cuda.is_available()
- Fallback to CPU if GPU unavailable
- See [[id:20251015114500-device_management][Device Management]]
