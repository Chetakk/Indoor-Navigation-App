* Description

Primary detection endpoint that orchestrates the entire detection pipeline.
Receives base64-encoded images, applies rotation correction, runs YOLO inference,
updates tracking, predicts collisions, and returns enriched detection data.

* Parameters

** Request Body (JSON)
- image :: str (required) - Base64-encoded image with data URI
- tracking_enabled :: bool (optional, default=True) - Enable tracking
- orientation :: dict (optional) - Gyroscope/device orientation data

* Returns

JSON object with:
- success :: bool
- detections :: list[dict] - Detection objects with tracking/collision data
- image_size :: [int, int]
- tracking_enabled :: bool
- collision_warnings :: int
- processing_time_ms :: float
