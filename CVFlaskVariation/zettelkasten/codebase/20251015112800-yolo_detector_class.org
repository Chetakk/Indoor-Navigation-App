* Singleton Pattern

Global instance prevents multiple model loads:
#+begin_src python
_detector = None

def get_detector(model_path='yolov8x-oiv7.pt', force_cpu=True):
    global _detector
    if _detector is None:
        _detector = YOLODetector(model_path, force_cpu)
    return _detector
#+end_src

See [[id:20251015118300-get_detector][get_detector()]]

* Why Singleton?

- Model load is expensive (~2-5 seconds)
- Model uses 500MB-2GB memory
- Single model can handle multiple concurrent requests
- Prevents GPU memory fragmentation

* Device Selection

#+begin_src python
self.device = 'cpu' if force_cpu else (
    'cuda' if torch.cuda.is_available() else 'cpu'
)
#+end_src

Priority:
1. If force_cpu=True → CPU
2. Else if CUDA available → GPU
3. Else → CPU

* Memory Usage

** Model Weights
- yolov8n: ~6MB
- yolov8s: ~22MB
- yolov8m: ~52MB
- yolov8l: ~88MB
- yolov8x: ~136MB (current)

** GPU VRAM (During Inference)
- Batch size 1: ~2-4GB
- Depends on input size

** CPU RAM
- ~500MB-1GB

* Thread Safety

Model inference is thread-safe in PyTorch.
Flask runs with threading=True, so multiple requests can use same model.
