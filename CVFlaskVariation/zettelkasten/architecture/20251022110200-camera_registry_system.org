* Overview

The Camera Registry System manages multiple connected camera clients (mobile phones, webcams, etc.) in a centralized server architecture. Enables remote monitoring, statistics tracking, and multi-camera dashboard viewing.

* Architecture Pattern

** Singleton Registry

#+BEGIN_SRC python
# Global registry instance (singleton pattern)
_registry = None

def get_camera_registry() -> CameraRegistry:
    global _registry
    if _registry is None:
        _registry = CameraRegistry()
    return _registry
#+END_SRC

Benefits:
1. Single source of truth for all cameras
2. Thread-safe access across Flask workers
3. Centralized lifecycle management
4. Easy statistics aggregation

* Camera Client Model

** Client Metadata

#+BEGIN_SRC python
class CameraClient:
    def __init__(self, camera_id, client_info):
        # Identity
        self.camera_id = camera_id or str(uuid.uuid4())
        self.camera_name = f'Camera {camera_id[:8]}'

        # Connection tracking
        self.connected_at = time.time()
        self.last_heartbeat = time.time()
        self.status = 'online'  # online, offline

        # Client info
        self.user_agent = client_info.get('user_agent')
        self.ip_address = client_info.get('ip')

        # State
        self.detection_active = False
        self.audio_enabled = False
        self.pathfinding_enabled = False
        self.dashboard_streaming_enabled = True

        # Statistics
        self.total_detections = 0
        self.total_frames = 0
        self.current_fps = 0
#+END_SRC

** Heartbeat Mechanism

Clients send periodic heartbeats to indicate they're alive:

#+BEGIN_SRC python
def update_heartbeat(self):
    self.last_heartbeat = time.time()
    if self.status == 'offline':
        self.status = 'online'
        logger.info(f"Camera {self.camera_id} back online")

def is_stale(self, timeout=30):
    """Check if camera hasn't sent heartbeat within timeout."""
    return (time.time() - self.last_heartbeat) > timeout
#+END_SRC

*Timeout Strategy:*
- Default timeout: 30 seconds
- Stale cameras marked as 'offline'
- Not removed immediately (allows reconnection)
- Periodic cleanup task checks for stale cameras

* Registry Operations

** Camera Registration

#+BEGIN_SRC python
def register_camera(self, camera_id=None, client_info=None):
    if camera_id and camera_id in self.cameras:
        # Existing camera reconnecting
        camera = self.cameras[camera_id]
        camera.update_heartbeat()
        return camera

    # New camera
    camera = CameraClient(camera_id=camera_id, client_info=client_info)
    self.cameras[camera.camera_id] = camera
    logger.info(f"New camera registered: {camera.camera_id}")
    return camera
#+END_SRC

** State Updates

Cameras push state updates with each frame:

def update_camera_state(self, camera_id, state_data):
    camera = self.get_camera(camera_id)
    if camera:
        camera.update_state(state_data)
        return True

State data includes:

** Frame Streaming

For dashboard streaming:

#+BEGIN_SRC python
def update_frame(self, frame_data: str):
    """Store latest frame as base64 JPEG."""
    self.latest_frame = frame_data
    self.frame_timestamp = time.time()

def get_latest_frame(self) -> Optional[str]:
    """Return None if frame is too old (>2 seconds)."""
    if self.frame_timestamp and (time.time() - self.frame_timestamp) > 2:
        return None
    return self.latest_frame
#+END_SRC

*Design Decision:* Only store latest frame (not queue)
- Reduces memory usage
- Dashboard always shows current state
- Old frames automatically expire

** Live Frame Streaming

#+BEGIN_SRC python
@cameras_bp.route('/<camera_id>/stream')
def stream_camera(camera_id):
    camera = registry.get_camera(camera_id)
    if not camera:
        return jsonify({'error': 'Camera not found'}), 404

    frame = camera.get_latest_frame()
    if not frame:
        return jsonify({'error': 'No recent frame'}), 404

    return jsonify({
        'frame': frame,  # base64 JPEG
        'timestamp': camera.frame_timestamp
    })
#+END_SRC

* Statistics Aggregation

** Registry-Wide Statistics

#+BEGIN_SRC python
def get_statistics(self):
    all_cameras = self.get_all_cameras()
    online_cameras = self.get_online_cameras()

    total_detections = sum(cam.total_detections for cam in all_cameras)
    total_frames = sum(cam.total_frames for cam in all_cameras)

    return {
        'total_cameras': len(all_cameras),
        'online_cameras': len(online_cameras),
        'offline_cameras': len(all_cameras) - len(online_cameras),
        'total_detections': total_detections,
        'total_frames': total_frames,
        'cameras': [cam.to_dict() for cam in all_cameras]
    }
#+END_SRC

* Thread Safety Considerations

** Concurrent Access

Flask runs with multiple workers/threads:
- Multiple cameras updating simultaneously
- Dashboard polling registry
- Cleanup tasks running

*No explicit locking in current implementation!*

Potential race conditions:
1. Dictionary modification during iteration
2. Concurrent state updates to same camera
3. Stale camera cleanup during registration

* Scalability Considerations

** Current Limitations

1. *In-memory storage*: Registry data lost on server restart
2. *Single server*: No horizontal scaling
3. *Polling-based*: Dashboard polls every 500ms (wasteful)
4. *No persistence*: Camera history not saved

** Potential Improvements

1. *Redis Backend*: Store registry in Redis for persistence
2. *WebSockets*: Push updates instead of polling
3. *Database*: Store camera history, statistics over time
4. *Load Balancer*: Sticky sessions for multi-server deployment
