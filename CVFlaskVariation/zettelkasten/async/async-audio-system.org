#+AUTHOR: CV-Project Documentation

* Overview

The audio system is a safety-critical component that manages speech synthesis for blind navigation. It implements a sophisticated state machine with priority-based queueing and intelligent interruption logic to ensure critical warnings are never missed.

* Design Goals

1. *Safety First*: Critical collision warnings ALWAYS interrupt lower priority audio
2. *No Audio Spam*: Rate limiting prevents overwhelming the user
3. *Smart Interrupts*: Avoid repeating the same warning within cooldown period
4. *Priority Queueing*: Process messages in order of importance
5. *Graceful Degradation*: Queue announcements when speech is active

* Audio State Machine

** State Definitions

| State             | Description                        | Can Be Interrupted By |
|-------------------+------------------------------------+-----------------------|
| IDLE              | No audio playing, ready for next   | N/A                   |
| SPEAKING_CRITICAL | Playing critical collision warning | Nothing (highest)     |
| SPEAKING_HIGH     | Playing high priority message      | CRITICAL only         |
| SPEAKING_NORMAL   | Playing normal announcement        | CRITICAL, HIGH        |
| SPEAKING_LOW      | Playing low priority info          | CRITICAL, HIGH, NORMAL |

** Implementation

#+BEGIN_SRC javascript
export function speak(text, priority = 'normal', isCriticalSceneChange = false) {
    if (!audioState.enabled) return;

    // GLOBAL RATE LIMITER: Prevent audio spam
    const now = Date.now();
    const timeSinceLastSpeech = now - audioState.lastAnySpeechTime;

    if (timeSinceLastSpeech < audioState.MIN_SPEECH_INTERVAL_MS) {
        console.log(`RATE LIMITED: Only ${timeSinceLastSpeech}ms since last speech`);
        queueAnnouncement(text, priority);
        return;
    }

    // Check if already speaking
    const isSpeaking = audioState.speechSynth.speaking || audioState.speechSynth.pending;

    if (isSpeaking) {
        // Use state machine to determine if should interrupt
        const shouldInterrupt = shouldInterruptAudio(priority, isCriticalSceneChange, text);

        if (shouldInterrupt) {
            console.log(`Interrupting for ${priority} priority`);
            audioState.speechSynth.cancel();
            audioState.queue = [];  // Clear queue
            speakImmediate(text, priority);
            return;
        } else {
            console.log(`Queueing ${priority} priority (cannot interrupt)`);
            queueAnnouncement(text, priority);
            return;
        }
    }

    // Not speaking, speak immediately
    speakImmediate(text, priority);
}

* Interrupt Decision Logic: shouldInterruptAudio()

** Decision Tree

#+BEGIN_SRC
shouldInterruptAudio(priority, isCriticalSceneChange, text)
  |
  +---> Priority = 'critical'?
  |     YES -> Check critical cooldown (3000ms)
  |            |
  |            +---> Within cooldown?
  |                  YES -> Fuzzy match same warning?
  |                         YES -> REJECT (duplicate)
  |                         NO -> ACCEPT (different critical)
  |                  NO -> ACCEPT (cooldown expired)
  |     NO -> Continue
  |
  +---> Priority = 'high'?
  |     YES -> Can interrupt 'normal' or 'low'
  |     NO -> Continue
  |
  +---> Priority = 'normal'?
  |     YES -> Can interrupt 'low' only
  |     NO -> Continue
  |
  +---> Priority = 'low'?
        YES -> Cannot interrupt anything
#+END_SRC

** Implementation

#+BEGIN_SRC javascript
function shouldInterruptAudio(priority, isCriticalSceneChange, text) {
    const currentPriority = audioState.currentPriority;
    const currentState = audioState.currentState;

    console.log(`Interrupt check: new=${priority}, current=${currentPriority}, state=${currentState}`);

    // CRITICAL priority
    if (priority === 'critical') {
        const timeSinceCritical = Date.now() - audioState.lastCriticalWarningTime;

        // Check if within cooldown period
        if (timeSinceCritical < audioState.CRITICAL_COOLDOWN_MS) {
            // Fuzzy match to prevent duplicate warnings
            const isSameWarning = fuzzyMatchWarning(text, audioState.currentText);

            if (isSameWarning) {
                console.log('Skipping duplicate critical warning (within cooldown)');
                return false;
            }
        }

        // Different critical warning or cooldown expired
        audioState.lastCriticalWarningTime = Date.now();
        return true;  // ALWAYS interrupt for critical
    }

    // HIGH priority
    if (priority === 'high') {
        // Can interrupt 'normal' or 'low', but NOT 'critical' or 'high'
        if (currentPriority === 'normal' || currentPriority === 'low') {
            return true;
        }
        return false;
    }

    // NORMAL priority
    if (priority === 'normal') {
        // Can only interrupt 'low'
        if (currentPriority === 'low') {
            return true;
        }
        return false;
    }

    // LOW priority
    // Cannot interrupt anything
    return false;
}
#+END_SRC

| high         | NO                | NO            | YES             | YES          |
| normal       | NO                | NO            | NO              | YES          |

* Fuzzy Matching for Duplicate Detection

** Location
   : app/static/js/modules/audio.js:300-320

** Purpose
   Prevent announcing "WARNING! Person directly ahead!" multiple times within 3 seconds.

** Algorithm
   1. Extract object class name from warning text
   2. Compare with previous warning's class name
   3. If same class, consider it a duplicate

** Implementation

#+BEGIN_SRC javascript
function fuzzyMatchWarning(newText, oldText) {
    if (!oldText) return false;

    // Extract class name (first word after common prefixes)
    const extractClass = (text) => {
        const cleaned = text
            .toLowerCase()
            .replace(/warning!?/i, '')
            .replace(/caution:?/i, '')
            .replace(/directly/i, '')
            .replace(/ahead/i, '')
            .trim();

        // Get first word (likely the object class)
        const match = cleaned.match(/^(\w+)/);
        return match ? match[1] : '';
    };

    const newClass = extractClass(newText);
    const oldClass = extractClass(oldText);

    console.log(`Fuzzy match: "${newClass}" vs "${oldClass}"`);

    return newClass === oldClass && newClass !== '';
}
#+END_SRC

function speakImmediate(text, priority) {
    console.log(`Speaking immediately: "${text}" [${priority}]`);

    const utterance = new SpeechSynthesisUtterance(text);

    // Adjust speech parameters based on priority
    if (priority === 'critical') {
        utterance.rate = 1.2;   // Fastest (20% faster)
        utterance.volume = 1.0; // Loudest
        utterance.pitch = 1.1;  // Slightly higher pitch
    } else if (priority === 'high') {
        utterance.rate = 1.1;   // Fast (10% faster)
        utterance.volume = 1.0;
        utterance.pitch = 1.0;
    } else if (priority === 'normal') {
        utterance.rate = 0.95;  // Slightly slower (5%)
        utterance.volume = 0.9;
        utterance.pitch = 1.0;
    } else {  // low
        utterance.rate = 0.9;   // Slower (10% slower)
        utterance.volume = 0.8; // Quieter
        utterance.pitch = 0.95;
    }

    // Update state machine
    audioState.isPlaying = true;
    audioState.currentPriority = priority;
    audioState.currentText = text;
    audioState.currentState = `SPEAKING_${priority.toUpperCase()}`;

    // Record timestamp
    audioState.lastAnySpeechTime = Date.now();

    if (priority === 'critical') {
        audioState.lastCriticalWarningTime = Date.now();
    }

    // Register completion handler
    utterance.onend = () => {
        console.log(`Finished speaking: "${text}"`);

        // Transition back to IDLE
        audioState.isPlaying = false;
        audioState.currentPriority = null;
        audioState.currentText = null;
        audioState.currentState = 'IDLE';

        // Process next message in queue after delay
        setTimeout(() => {
            processAudioQueue();
        }, TimingConfig.audio.queueProcessDelay);  // 200ms default
    };

    // Speak the utterance
    audioState.speechSynth.speak(utterance);
}

function queueAnnouncement(text, priority) {
    console.log(`Queueing: "${text}" [${priority}]`);

    // Check for duplicates in queue
    const isDuplicate = audioState.queue.some(item =>
        item.text === text && item.priority === priority
    );

    if (isDuplicate) {
        console.log('Skipping duplicate announcement in queue');
        return;
    }

    // Add to queue
    audioState.queue.push({ text, priority, timestamp: Date.now() });

    // Limit queue size (prevent unbounded growth)
    if (audioState.queue.length > 10) {
        console.warn('Queue full, removing oldest non-critical');

        // Remove oldest non-critical message
        const nonCriticalIndex = audioState.queue.findIndex(
            item => item.priority !== 'critical'
        );

        if (nonCriticalIndex !== -1) {
            audioState.queue.splice(nonCriticalIndex, 1);
        }
    }
}
#+END_SRC

** Processing Queue

*** Location

#+BEGIN_SRC javascript
function processAudioQueue() {
    if (!audioState.enabled || audioState.isPlaying || audioState.queue.length === 0) {
        return;
    }

    console.log(`Processing queue (${audioState.queue.length} items)`);

    // Sort by priority (critical -> high -> normal -> low)
    const priorityOrder = { critical: 0, high: 1, normal: 2, low: 3 };
    audioState.queue.sort((a, b) =>
        priorityOrder[a.priority] - priorityOrder[b.priority]
    );

    // Get highest priority message
    const announcement = audioState.queue.shift();

    console.log(`Dequeued: "${announcement.text}" [${announcement.priority}]`);

    // If critical, clear remaining queue and cancel current speech
    if (announcement.priority === 'critical') {
        console.log('Critical announcement - clearing queue and interrupting');
        audioState.queue = [];
        audioState.speechSynth.cancel();
    }

    // Speak the announcement
    speakImmediate(announcement.text, announcement.priority);
}
#+END_SRC

** Queue Behavior

*** Queue Sorting
    - Always sorted by priority before processing
    - Critical messages always processed first
    - FIFO within same priority level

*** Queue Size Limiting
    - Maximum 10 messages in queue
    - When full, remove oldest *non-critical* message
    - Critical messages are never removed

*** Queue Clearing
    - Cleared on critical interrupt
    - Cleared on scene change with critical collision
    - Cleared when user stops detection

* Common Pitfalls and Solutions

** Pitfall 1: Audio Spam from Rapid Detections

*Problem:* Detection runs at 10 FPS, each frame tries to announce

#+BEGIN_SRC javascript
// BAD: Announces every frame (100 times/second)
detections.forEach(d => speak(d.class_name));
#+END_SRC

*Solution:* Use per-class interval tracking + global rate limiter

#+BEGIN_SRC javascript
// GOOD: Respects 800ms global + per-class intervals
const lastTime = lastAnnouncement[className] || 0;
if (Date.now() - lastTime > announcementInterval) {
    speak(announcement);
    lastAnnouncement[className] = Date.now();
}
#+END_SRC

** Pitfall 2: Repeating Critical Warnings

*Problem:* "WARNING! Person ahead!" announced every 30ms

#+BEGIN_SRC javascript
// BAD: No cooldown for critical warnings
if (collision.severity === 'high') {
    speak(warningText, 'critical');  // Repeats every frame!
}
#+END_SRC

*Solution:* Fuzzy match + 3-second cooldown

#+BEGIN_SRC javascript
// GOOD: Only announce if different warning or cooldown expired
if (priority === 'critical') {
    const timeSinceCritical = Date.now() - lastCriticalWarningTime;

    if (timeSinceCritical < 3000 &&
        fuzzyMatchWarning(text, currentText)) {
        return;  // Skip duplicate
    }

    speak(warningText, 'critical');
}
#+END_SRC

** Pitfall 3: Queue Unbounded Growth

*Problem:* Queue grows indefinitely if announcements faster than playback

#+BEGIN_SRC javascript
// BAD: No size limit
audioState.queue.push(announcement);  // Can grow to 1000s of items
#+END_SRC

*Solution:* Limit queue to 10 items, remove oldest non-critical

#+BEGIN_SRC javascript
// GOOD: Bounded queue with eviction
if (audioState.queue.length > 10) {
    const nonCriticalIndex = audioState.queue.findIndex(
        item => item.priority !== 'critical'
    );
    audioState.queue.splice(nonCriticalIndex, 1);
}
