* Overview

The backend uses Python's =threading= module to run GPU-intensive depth estimation in parallel with the main Flask request handler. This prevents blocking the detection pipeline while depth maps are being computed.

* AsyncDepthWorker Class

** Location
   : app/services/depth_estimator.py:230-310

** Design Pattern
   The AsyncDepthWorker is a *daemon thread* that continuously processes images from a queue.

** Implementation

#+BEGIN_SRC python
class AsyncDepthWorker(threading.Thread):
    """Background thread that continuously updates depth maps."""

    def __init__(self, model, transform, device, cache, input_size=256, use_fp16=False):
        super().__init__(daemon=True)  # Daemon thread - exits with main app
        self.model = model
        self.transform = transform
        self.device = device
        self.cache = cache
        self.input_size = input_size
        self.use_fp16 = use_fp16

        # Thread-safe image queue
        self.image_queue = deque(maxlen=2)  # Only keep latest 2 frames
        self.queue_lock = threading.Lock()
        self.running = True
        self.frame_count = 0

    def add_image(self, image_bgr):
        """Add image to processing queue (thread-safe)."""
        with self.queue_lock:
            self.image_queue.append(image_bgr.copy())  # Deep copy!

    def run(self):
        """Main worker loop - processes images from queue."""
        while self.running:
            # Get image from queue
            image_bgr = None
            with self.queue_lock:
                if len(self.image_queue) > 0:
                    image_bgr = self.image_queue.popleft()

            if image_bgr is None:
                time.sleep(0.01)  # Wait for new images (10ms)
                continue

            # Process depth estimation (GPU-intensive, runs in background)
            try:
                depth_map = self._estimate_depth(image_bgr)
                if depth_map is not None:
                    self.cache.set(depth_map)  # Thread-safe write
                    self.frame_count += 1
            except Exception as e:
                logger.error(f"Error in async depth worker: {e}")

    def stop(self, timeout=2.0):
        """Stop the worker thread gracefully."""
        self.running = False
        self.join(timeout=timeout)
        if self.is_alive():
            logger.warning("Async depth worker did not stop in time")
#+END_SRC

** Key Features

*** Daemon Thread (daemon=True)
    - Automatically terminates when main process exits
    - Prevents hanging background processes
    - No need for explicit cleanup in most cases

*** Bounded Queue (deque(maxlen=2))
    - Only keeps the 2 most recent frames
    - Automatically discards old frames when new ones arrive
    - Prevents memory accumulation if processing is slow
    - Non-blocking: always accepts new frames

*** Thread-Safe Queue Operations
    - =queue_lock= protects =image_queue= from concurrent access
    - Always use =with self.queue_lock:= when accessing queue
    - Deep copy (=image_bgr.copy()=) prevents shared memory issues

*** Graceful Shutdown
    - =stop()= method sets =self.running = False=
    - =join(timeout=2.0)= waits up to 2 seconds for thread to exit
    - Logs warning if thread doesn't stop in time

#+BEGIN_SRC python
class DepthMapCache:
    """Thread-safe cache for depth maps."""

    def __init__(self, maxlen=10):
        self.maxlen = maxlen
        self.depth_map = None
        self.timestamp = 0
        self.lock = threading.Lock()

    def set(self, depth_map):
        """Store depth map (thread-safe)."""
        with self.lock:
            self.depth_map = depth_map
            self.timestamp = time.time()

    def get(self):
        """Retrieve depth map (thread-safe)."""
        with self.lock:
            return self.depth_map, self.timestamp

    def is_valid(self, max_age_seconds=1.0):
        """Check if cached depth is still fresh."""
        with self.lock:
            if self.depth_map is None:
                return False
            age = time.time() - self.timestamp
            return age < max_age_seconds

    def clear(self):
        """Clear the cache."""
        with self.lock:
            self.depth_map = None
            self.timestamp = 0
#+END_SRC

** Key Features

*** Atomic Read/Write
    - Always acquire lock before accessing depth_map or timestamp
    - Read and write operations are atomic
    - Prevents torn reads (reading while writing)

*** Age Tracking
    - Timestamp recorded on every write
    - =is_valid()= checks if data is recent enough
    - Default expiration: 1 second

*** Single-Slot Cache
    - Only stores the most recent depth map
    - No complex eviction logic needed
    - Optimized for real-time streaming

#+BEGIN_SRC python
class AutoCalibrator:
    """Auto-calibrates depth scale using pinhole camera estimates."""

    def __init__(self, window_size=20):
        self.scales = deque(maxlen=window_size)
        self.lock = threading.Lock()

    def add_sample(self, pinhole_distance, relative_depth):
        """Add a calibration sample (thread-safe)."""
        if pinhole_distance is None or relative_depth is None:
            return

        scale = pinhole_distance / relative_depth

        # Sanity check: reasonable range for depth scale
        if 0.001 <= scale <= 0.1:
            with self.lock:
                self.scales.append(scale)

    def get_scale(self):
        """Get current calibrated scale (median of samples)."""
        with self.lock:
            if len(self.scales) < 3:
                return None  # Need at least 3 samples
            return float(np.median(list(self.scales)))

    def reset(self):
        """Clear all calibration data."""
        with self.lock:
            self.scales.clear()
#+END_SRC

** Key Features

*** Median-Based Calibration
    - Uses median instead of mean (robust to outliers)
    - Requires minimum 3 samples before returning a value
    - Rolling window of 20 samples

*** Sanity Check
    - Rejects scales outside [0.001, 0.1] range
    - Prevents corrupted calibration from bad data
    - Fail-safe: calibration degrades gracefully

@bp.route('/detect_image', methods=['POST'])
def detect_image():
    """Process image from browser and return detection results."""
    start_time = time.time()

    # 1. Decode image from request
    data = request.get_json()
    image_bytes = base64.b64decode(data['image'].split(',')[1])
    image = Image.open(BytesIO(image_bytes))
    image_bgr = cv2.cvtColor(np.array(image), cv2.COLOR_RGB2BGR)

    # 2. Run YOLO detection (CPU-based, synchronous)
    detector = get_detector()
    results = detector.detect(image_bgr)

    # 3. Initialize depth estimator (lazy loading)
    depth_estimator = get_depth_estimator(force_cpu=True)

    # 4. Queue image for async depth processing
    # NOTE: This does NOT wait for depth estimation to complete!
    if depth_estimator.async_enabled and depth_estimator.async_worker:
        depth_estimator.async_worker.add_image(image_bgr)

    # 5. Estimate distance for each detection
    for r in results:
        for box in r.boxes:
            # This retrieves cached depth from async worker
            # If no depth is available yet, falls back to pinhole/bbox
            distance_info = depth_estimator.estimate_distance_with_depth(
                image_bgr, bbox, class_name,
                motion_scale=motion_scale,
                motion_confidence=motion_confidence
            )

    # 6. Return response (depth processing continues in background)
    return jsonify(response_data)

# Global instances (thread-safe)
_detector = None
_depth_estimator = None

def get_detector():
    """Get or create global YOLO detector instance."""
    global _detector
    if _detector is None:
        _detector = YOLODetector(
            model_path=YOLO_MODEL_PATH,
            confidence_threshold=YOLO_CONFIDENCE_THRESHOLD
        )
    return _detector

def get_depth_estimator(force_cpu=False):
    """Get or create global depth estimator instance."""
    global _depth_estimator
    if _depth_estimator is None:
        _depth_estimator = DepthEstimator(
            use_async=DEPTH_ASYNC_ENABLED,
            use_fp16=DEPTH_USE_FP16,
            input_size=DEPTH_INPUT_SIZE
        )
        _depth_estimator.initialize()  # Starts async worker
    return _depth_estimator
#+END_SRC

** Thread Safety Considerations
   - Flask runs in *multiple worker processes* (not threads by default)
   - Each worker process has its own copy of global variables
   - No need for locks on =_detector= and =_depth_estimator=
   - Each process has its own AsyncDepthWorker thread

* Graceful Shutdown Handler

** Location
   : run.py:30-45

** Implementation

#+BEGIN_SRC python
def cleanup_and_exit(signum=None, frame=None):
    """Cleanup resources before exiting."""
    print("Shutting down server...")

    # Stop async depth worker
    if _depth_estimator is not None:
        _depth_estimator.cleanup()
        if _depth_estimator.async_worker:
            _depth_estimator.async_worker.stop(timeout=3.0)

    # Clear GPU memory
    if torch.cuda.is_available():
        torch.cuda.empty_cache()

    sys.exit(0)

# Register signal handlers
signal.signal(signal.SIGINT, cleanup_and_exit)   # Ctrl+C
signal.signal(signal.SIGTERM, cleanup_and_exit)  # Kill command
atexit.register(cleanup_and_exit)                # Normal exit
#+END_SRC

** Cleanup Steps
   1. Call =cleanup()= on depth estimator
   2. Stop async worker thread (wait up to 3 seconds)
   3. Clear CUDA cache to free GPU memory
   4. Exit cleanly with status code 0

* Common Pitfalls and Solutions

** Pitfall 1: Shared Memory Corruption

*Problem:* Passing numpy array directly to thread without copying

#+BEGIN_SRC python
# BAD: Shared memory between threads
self.image_queue.append(image_bgr)  # Main thread may modify image_bgr later
#+END_SRC

*Solution:* Always deep copy

#+BEGIN_SRC python
# GOOD: Each thread has independent copy
self.image_queue.append(image_bgr.copy())
#+END_SRC

** Pitfall 2: Deadlock with Nested Locks

*Problem:* Acquiring same lock twice

#+BEGIN_SRC python
# BAD: Deadlock if get() calls is_valid()
def get(self):
    with self.lock:
        if self.is_valid():  # is_valid() also needs lock!
            return self.depth_map
#+END_SRC

*Solution:* Use separate internal methods without locks

#+BEGIN_SRC python
# GOOD: is_valid() assumes lock is already held
def get(self):
    with self.lock:
        if self._is_valid_unlocked():
            return self.depth_map
#+END_SRC

** Pitfall 3: Forgetting to Stop Thread on Exit

*Problem:* Thread keeps running after main process exits

#+BEGIN_SRC python
# BAD: Non-daemon thread hangs on exit
worker = threading.Thread(target=process_images)
worker.start()
#+END_SRC

*Solution:* Use daemon=True or explicit stop()

#+BEGIN_SRC python
# GOOD: Daemon thread auto-exits with main process
worker = threading.Thread(target=process_images, daemon=True)
worker.start()

# BETTER: Graceful shutdown with cleanup
worker.stop(timeout=3.0)
#+END_SRC
