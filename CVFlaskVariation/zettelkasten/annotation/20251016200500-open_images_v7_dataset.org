* Overview

Open Images v7 is a large-scale dataset by Google containing millions of annotated images across 600+ object classes. The CV-Project uses YOLOv8x-oiv7 model pre-trained on this dataset.

* Dataset Statistics

- *Images*: 9 million+ training images
- *Classes*: 600+ object categories
- *Annotations*: Bounding boxes, segmentation masks, visual relationships
- *License*: Creative Commons (various)
- *Source*: Google Research

* Class Structure

** High-Level Categories

- Animals (mammals, birds, fish, insects)
- Vehicles (cars, bikes, boats, aircraft)
- Furniture (chairs, tables, beds, sofas)
- Food (fruits, vegetables, dishes)
- Household objects
- Electronics
- Clothing and accessories
- Sports equipment
- Musical instruments
- Plants and nature

* Model: YOLOv8x-oiv7

** Specifications

- *Architecture*: YOLOv8 Extra Large variant
- *Training data*: Open Images v7
- *Classes*: 600+
- *Input size*: 640x640 (default)
- *Format*: PyTorch (.pt)

** Usage in CV-Project

File: app/services/yolo_detector.py

#+BEGIN_SRC python
self.model = YOLO('yolov8x-oiv7.pt')

** Performance Characteristics

- High accuracy on diverse object classes
- Good generalization to indoor scenes
- Conservative confidence threshold (0.30) for safety-critical navigation
- Handles 600+ classes without custom training

* Accessing Open Images Dataset

** Download Options

1. *FiftyOne* (recommended):
#+BEGIN_SRC python
import fiftyone as fo
import fiftyone.zoo as foz

# Download specific classes
dataset = foz.load_zoo_dataset(
    "open-images-v7",
    split="train",
    label_types=["detections"],
    classes=["Person", "Chair", "Table", "Door"],
    max_samples=1000
)

# Export to YOLO format
dataset.export(
    export_dir="open-images-subset",
    dataset_type=fo.types.YOLOv5Dataset,
    label_field="ground_truth"
)
#+END_SRC

2. *Direct download*: https://storage.googleapis.com/openimages/web/index.html

3. *AWS S3*: s3://open-images-dataset/

* Future Training Considerations

** Option 1: Fine-tune on OIV7 Subset

- Select indoor-relevant classes from OIV7
- Fine-tune existing yolov8x-oiv7 model
- Maintains broad object recognition

** Option 2: Train on Custom Dataset

- Annotate indoor navigation scenarios using CVAT
- Train from yolov8x-oiv7 weights
- Add domain-specific classes (e.g., "wet_floor", "doorway")

** Option 3: Hybrid Approach

- Combine OIV7 subset + custom annotations
- Best of both worlds: breadth + specialization
- Recommended for production deployment
