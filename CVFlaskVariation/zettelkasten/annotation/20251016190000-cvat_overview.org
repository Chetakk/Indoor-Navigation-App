* Overview

CVAT (Computer Vision Annotation Tool) is an open-source, web-based annotation platform developed by Intel. It provides a comprehensive environment for annotating images and videos for computer vision tasks.

* Core Features

** Multi-Format Support
- Supports multiple annotation types: bounding boxes, polygons, polylines, points, cuboids, skeletons
- Import/export in various formats: YOLO[fn:1], COCO[fn:2], Pascal VOC[fn:3], TFRecord, etc.
- Video annotation with frame interpolation

See [[id:20251016200300][Annotation Formats Comparison]] for detailed format comparison.

** Collaboration Features
- Multi-user support with role-based access control
- Task assignment and management
- Quality control through annotation review workflow
- Real-time collaboration on annotation tasks

** Advanced Capabilities
- Automatic annotation using pre-trained models
- Semi-automatic annotation with tracking algorithms
- Keyboard shortcuts for rapid annotation
- Annotation versioning and history
- Custom attribute definitions for objects

* Architecture

** Components
- Web-based frontend (React)
- REST API backend (Django)
- PostgreSQL database for metadata
- File storage for images/videos
- Optional: GPU support for auto-annotation models

** Deployment Options
- Docker containers (recommended)
- Kubernetes for scaling
- Cloud deployment (AWS, Azure, GCP)
- On-premise installation

* Use Cases for CV Project

** Current Application
Our indoor navigation project uses YOLOv8x for object detection. CVAT could be used for:
- Creating custom training datasets for indoor objects
- Fine-tuning YOLO on specific furniture/obstacle classes
- Annotating edge cases for model improvement
- Building validation datasets for accuracy testing

** Integration Points
- Export annotations in YOLO format[fn:1] for training - see [[id:20251016200400][CVAT YOLO Integration]]
- Validate detection accuracy against ground truth
- Collect user feedback through annotation interface
- Build domain-specific datasets (indoor navigation scenarios)
- Apply augmentation using utilities/augScript.py - see [[id:20251016200800][Dataset Augmentation Strategies]]

* Advantages

- Free and open-source
- Active community and regular updates
- Extensive format support
- Scalable for large annotation projects
- Built-in quality control mechanisms
- GPU-accelerated auto-annotation

* Limitations

- Requires server infrastructure for deployment
- Learning curve for advanced features
- Resource-intensive for large video files
- Requires manual setup for custom models
