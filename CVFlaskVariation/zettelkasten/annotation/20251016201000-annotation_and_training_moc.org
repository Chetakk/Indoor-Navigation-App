This Map of Content (MOC) serves as the central hub for all annotation, dataset creation, and model training topics in the CV-Project. Use this as your starting point for any annotation-related tasks.

* Quick Commands

** Frame Extraction

#+BEGIN_SRC bash
python utilities/framer.py video.mp4 -o frames -r 640x640 -i 10
#+END_SRC

** Image Enhancement

#+BEGIN_SRC bash
python utilities/enhancer.py frames -o enhanced --preset yolo
#+END_SRC

** Dataset Augmentation

#+BEGIN_SRC bash
python utilities/augScript.py annotated_data output_dataset \
    --augmentation_factor 5 --train_ratio 0.8
#+END_SRC

** YOLOv8 Training

#+BEGIN_SRC bash
# Fine-tune from OIV7 model
yolo train data=dataset/data.yaml model=yolov8x-oiv7.pt epochs=50

# Train from scratch
yolo train data=dataset/data.yaml model=yolov8x.yaml epochs=100

# Resume training
yolo train resume model=runs/detect/train/weights/last.pt
#+END_SRC

** Validation

#+BEGIN_SRC bash
yolo val data=dataset/data.yaml model=runs/detect/train/weights/best.pt
#+END_SRC

** Inference

#+BEGIN_SRC bash
yolo predict model=runs/detect/train/weights/best.pt source=test_images/
#+END_SRC
